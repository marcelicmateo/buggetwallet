# wallet_importer — notes for Claude

Pure Dart. **The only code that knows bank formats.** Turns PBZ .xls, Revolut .xlsx/.csv into
`NormalizedTransaction`s (contract v1). The app and `wallet_core` never see bank files.

## Files
- `importer.dart` — `importBankFile(name, bytes)`: detects the format, maps columns → `parseRows`.
- `xls_reader.dart` (own BIFF8 reader), `xlsx_reader.dart` (`archive` + `xml`), `csv_reader.dart`.
- `model.dart` — `NormalizedTransaction`, `ImportBatch`. `ids.dart` — `transactionId`, `fnv1a36`.

## Rules
- `transactionId` must stay identical to v1 (date + FNV-1a of date|amount|description + occurrence index):
  re-imports must never duplicate, across v1 and v2. Changing it is a breaking change.
- A contract change (new field on `NormalizedTransaction`) is additive and optional.
- Format details: `docs/context/IMPORT_FORMATS.md`.

## Tests
- `test/importer_test.dart`, fixtures in `test/fixtures/` — **synthetic only**, generated by
  `tools/make_fixtures.py`. Never add a real export, even trimmed or anonymised.
- Run: `tools/build.sh test` from the repo root.
