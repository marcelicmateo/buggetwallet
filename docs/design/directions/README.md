# Kept design directions (2026-10-19)

Six of ten directions the owner kept: D1 Baseline, D3 Ledger, D5 Soft Blocks, D6 Receipt, D8 Calendar, D10 Voice First.
Each `dNN-<Screen>.dc.html` is one 390×844 phone screen (static HTML/CSS, sample numbers only) from the claude.ai design
canvas https://claude.ai/artifact/Vfy7FfEXoXVDKAJgYG4NKU (private). They need the canvas runtime (`support.js`) to render
exactly, but the markup and inline styles are readable as layout and style reference for the Flutter screens.
`SPEC.md` is the brief they were built from; `canvas.json` the layout; `Main.dc.html` the overview board.
Decisions, palettes and the screen list: `docs/context/DESIGN_DECISIONS.md` §6. Final direction not chosen yet.
