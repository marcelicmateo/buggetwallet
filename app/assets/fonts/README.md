# Fonts (Manrope and JetBrains Mono)

Engineer theme (ENG E1, `docs/context/ENG_UI_SPEC.md` §4.3). Both families are SIL Open Font License 1.1. The TTF files are unmodified
copies of the official files (only `Manrope[wght].ttf` was renamed, to avoid brackets in an asset path). Replaces Inter and IBM Plex Mono.

## Manrope (text, 400/500/600/700/800)
- Source: google/fonts, `ofl/manrope/Manrope[wght].ttf` (variable, wght 200-800), commit `b31870aff700ab7a1d74fa0c6887d95beb9e0037`
  (last change to that folder when downloaded 2026-11-02). google/fonts ships no static Manrope files.
- File: `Manrope-VariableFont_wght.ttf`, sha256 `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.
- Licence: `OFL-Manrope.txt` (verbatim `ofl/manrope/OFL.txt`).
